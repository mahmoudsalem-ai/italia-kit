برومبتات جاهزة للنسخ

غيّر اللي بين القوسين [ ] بس.

١. السيناريو (في Claude)

اكتبلي فكرة فيديو قصير ٢٠ ثانية عن [الموضوع] لجمهور مصري. قسّمه لـ ٥ مشاهد في جدول: المشهد / وصف الصورة / الحركة / الكلام أو الصوت. وفي الآخر اكتب برومبت صورة بالإنجليزي لكل مشهد.

٢. الشخصية الثابتة (في Gemini أو ChatGPT)

Create a character reference sheet of [character description], front view, side view and full body, plain background, same outfit and face in all views, [style: Pixar 3D / realistic / anime], vertical 9:16.

٣. صورة المشهد (ارفع صورة الشخصية معاها)

Using the uploaded character exactly as is, show them [action] in [place], [time of day + lighting], cinematic, vertical 9:16, no text.

٤. الحركة (في Vibes أو Higgsfield)

Slow camera push-in, the character [one simple movement], natural motion, stable face, 5 seconds.

حوّل Claude لاستوديو فيديو

شركة Higgsfield نزّلت سكيلز رسمية ومجانية بتعلّم Claude يختار الموديل، ويكتب البرومبت، ويشغّل التوليد بنفسه.

1

نزّل السكيلز

github.com/higgsfield-ai/skills

لو بتستخدم Claude Code: npx skills add higgsfield-ai/skills

2

وصّل حساب Higgsfield

من الـ Connectors في Claude، أو بالـ CLI بتاعهم وسجّل دخول بنفسك.

3

اختار السكيل المناسب

ريل من غير وش بتعليق صوتي ← faceless-video
صورة / فيديو / إعلان UGC ← generate
صورة غلاف يوتيوب ← youtube-thumbnail
شخصية وشّها ثابت ← soul-id

أهم سطر في البرومبت 👇

اعملّي [ريل 20 ثانية عن ...]. اعرض الموديلات والتكلفة المتوقعة الأول، ومتبدأش التوليد غير بموافقتي.

السكيلز ببلاش، بس التوليد بيصرف كريديت Higgsfield. ابدأ بالكريديت المجاني.

اعمل نسخة كرتون منك

ارفع صورة ليك (وشك واضح ونور حلو) في ChatGPT أو Gemini، والصق البرومبت ده:

Turn the person in this photo into a 3D Pixar-style animated character. Keep the same face shape, hairstyle, beard, glasses and skin tone so it is clearly him. Friendly expression, sitting at a desk with a podcast microphone, warm purple and orange studio lights, vertical 9:16, high detail, no text.
1

ثبّت الشخصية

احفظ أحسن صورة طلعت، وارفعها هي نفسها مع كل برومبت جاي واكتب: Use this exact character.

2

سجّل بصوتك

سجّل الكلام بالمايك أو الموبايل في مكان هادي، جملة جملة بينهم ثانية سكوت.

3
